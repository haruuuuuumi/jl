# Jeolee Cupids
An independent fan home for Jeo Ong, Gehlee Dangca and their fandom, Cupids.
## Audience and jobs
New visitors learn who Jeolee are and meet the fandom. Returning Cupids find sourced updates and replay clips. Contributors suggest clips, collections, references, and corrections; an admin reviews submissions before publication.
## Approved structure
Home introduces the people and previews highlights. About carries visible biographies, sourced milestones and the fanbase directory. Updates is the chronological news archive. Moments owns search, collections and media. Cupids’ Space is the approved shared reference.
## Brand commitments
Modern pink and black, preserving the existing photography, Pathway Extreme display type and DM Sans UI. Do not return to a newspaper/editorial aesthetic. Use the JL favicon.
The footer contains only: Managed by Jeolee – Amats GDM.
## Access and content
Browsing and contributions are public, with no visitor accounts or My List. Admin uses its existing password session. New clips, suggested collections and wiki edits require approval.
Approved fanbase sources: @jeoleenation, @official_jeolee and @withjeolee. Reader checks run at noon and midnight Asia/Manila; failed checks retain saved stories and never relabel old content as new. Access failures do not authorize bypasses.
Keep creator credits, original source links, original publication dates, and the distinction between publisher reports, fanbase posts and Cupid contributions. Preserve existing catalog edits, deletions and moderation records.
## Current implementation contract
User approved implementation of the complete site review. Shared real-page navigation, a compact Home, dedicated Updates/Moments, local contribution drafts and receipts, contextual submission flows, safer admin review, and responsive image variants are in scope. Hosting remains Cloudflare with the existing D1 database and GitHub repository.
